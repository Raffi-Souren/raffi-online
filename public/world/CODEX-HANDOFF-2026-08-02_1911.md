## 1. What was done (this arc)

### 1.1 InfiniTown-style building massing (owner choice A)

**Problem:** Buildings read as single extruded boxes (Minecraft). Blur did not fix that.

**Solution:** Procedural **base / shaft / crown** grammar + storey ledges + pilasters + punched windows + storefronts + layered roofs.

| File | Change |
|---|---|
| `public/world/gen/buildings.js` | **Rewritten.** Core: `planShells`, `buildBuilding`, storey belts, pilasters, `addWindowGrid`, storefronts, caps |
| `public/world/data/blocks.json` | Per-archetype `massing: { ... }`; raised `triBudget`; stronger vertex lighting contrast |
| `public/world/gen/builder.js` | `heightAmb(y)` — soft height wash on walls |

**`massing` keys** (in `blocks.json` archetypes):

| Key | Meaning |
|---|---|
| `baseFloors` | Plinth storeys (`0` = no plinth) |
| `baseOutset` | How much wider plinth is than shaft |
| `baseHeightScale` | Plinth taller than normal floor height |
| `baseColor` / `ledgeColor` / `frameColor` | Vertex tint hints |
| `pilasters` | Corner + mid-face posts (brownstones) |
| `belts` | Storey ledges (`false` for warehouses) |
| `windowStyle` | `recessed` \| `curtain` \| `none` |

**Still honored:** `setback` modes `none` | `single` | `stepped`; caps `cornice` | `parapet` | `mech-box` | `crown` | `sawtooth` | `gable` | `open-deck`.

City geometry builds **at boot** from JSON + seed. Reload after edits.
